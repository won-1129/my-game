## 함수 설명
drawStudentWarning은 장애물이 온다는 경고를 알려주는 함수이다.
이 함수를 지울시에 사전경고 없이 장애물이 매우 빠른 속도로 오기때문에 플레이어는 속수무책으로 당할 수 밖에 없다.
const timeUntilSpawn = nextStudentSpawnTime - elapsedSeconds; 이 가장 중요한 이유: 장애물이 등장할 시각과 게임의 진행시간 남은 시간을 계산하는 핵심 공식이기 때문에 이 계산값이 있어야 경고를 언제 띄우고 끌 수 있는지 판정을 할 수 있다.
